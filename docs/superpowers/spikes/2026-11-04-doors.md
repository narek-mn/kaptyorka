## Claude Code (verified 2026-11-04, 2.1.318)

Door works: **yes** (verified in the earlier spike; not rerun here). Discovery: `~/.claude/sessions/<pid>.json`
gives `messagingSocketPath`; the token is in `~/.claude/sessions/<pid>.*.key` (`peerToken`).
The verified spike script, verbatim:

```python
#!/usr/bin/env python3
"""Post a text message into a running Claude Code session's inbox socket.
Usage: post.py <pid> <text> [--noauth]"""
import glob, json, socket, sys, os
pid, text = sys.argv[1], sys.argv[2]
home = os.path.expanduser("~/.claude/sessions")
sock_path = json.load(open(f"{home}/{pid}.json"))["messagingSocketPath"]
s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.connect(sock_path)
if "--noauth" not in sys.argv:
    key = json.load(open(glob.glob(f"{home}/{pid}.*.key")[0]))["peerToken"]
    s.sendall((json.dumps({"type": "auth", "token": key}) + "\n").encode())
s.sendall((json.dumps({"type": "user", "message": {"role": "user", "content": text}}) + "\n").encode())
s.shutdown(socket.SHUT_WR)
s.settimeout(5)
try:
    reply = s.recv(65536)
    print("reply:", reply.decode(errors="replace") or "(none, closed)")
except socket.timeout:
    print("reply: (none within 5s)")
s.close()
```

### (a) Port discovery: `join` must make the TUI listen
- Run and seen: plain `opencode` (TUI) opens **no** TCP listener at all (only outgoing HTTPS and
  unix socketpairs). There is nothing to discover.
- Run and seen: `opencode --port 0` listens on `127.0.0.1:4096`; a second instance started with
  `--port 0` while 4096 was taken got a random port (43313). So `--port 0` = "4096, else random".
- Run and seen: config `"server": {"port": 0}` is rejected ("Expected a value greater than 0").
  A fixed `server.port` works per the config schema (read in the binary) but collides when two
  TUIs run, so do not use it.
- **Chosen:** `join` makes `opencode` start with `--port 0` (shell alias or wrapper:
  `alias opencode='opencode --port 0'`), and the bridge finds the port by pid. Both
  methods were run and returned 4096 for the TUI pid:
  - `lsof -a -p <pid> -iTCP -sTCP:LISTEN`
  - `/proc` only (no `lsof` needed):

```python
import os, sys
pid = sys.argv[1]
inodes = set()
for fd in os.listdir(f"/proc/{pid}/fd"):
    try: l = os.readlink(f"/proc/{pid}/fd/{fd}")
    except OSError: continue
    if l.startswith("socket:["): inodes.add(l[8:-1])
for f in ("/proc/net/tcp", "/proc/net/tcp6"):
    for line in open(f).readlines()[1:]:
        c = line.split()
        if c[3] == "0A" and c[9] in inodes:   # 0A = LISTEN
            print(int(c[1].split(":")[1], 16))
```

### (b) Push request (run and seen)
- `GET http://127.0.0.1:<port>/session` -> 200, JSON array. Each item has `id` (`ses_...`),
  `directory` (absolute cwd), `title`, `time.created`, `time.updated` (ms). Optional query
  `?directory=<path>` exists (read in `GET /doc`, the server's OpenAPI).
- `POST http://127.0.0.1:<port>/session/<id>/prompt_async`, header `content-type: application/json`,
  body:

```json
{"parts":[{"type":"text","text":"[kaptyorka] What is the team word? Answer with just the word."}]}
```

  -> **204 No Content**. The TUI showed the message and the reply within a few seconds;
  `GET /session/<id>/message` then listed it as a `user` message followed by the assistant reply.
- No session exists until the first prompt in the TUI; `GET /session` was `[]` before that.

### (d) Plugin that adds context (run and seen)
File `~/.config/opencode/plugins/<name>.js` (global) or `.opencode/plugins/` (project), loaded at
start. Hook names found in the binary: `chat.message`, `chat.params`, `chat.headers`,
`experimental.chat.system.transform`, `experimental.chat.messages.transform`,
`experimental.session.compacting`, `tool.execute.before/after`, `shell.env`, plus an `event`
handler. The docs page only documents the events and `experimental.session.compacting`.
`experimental.chat.system.transform` runs before every model call (seen twice per prompt) and
`output.system.push(text)` reached the model: it answered the marker word `PINEAPPLE-42` that
only the plugin knew. `chat.message` fires once per user message with `sessionID`;
`session.created` arrives as an event. Working minimal plugin:

```js
import fs from "node:fs";
const LOG = "/path/to/oc-plugin.log";
export const Kaptyorka = async ({ directory, worktree }) => {
  fs.appendFileSync(LOG, JSON.stringify({ loaded: true, directory, worktree, pid: process.pid }) + "\n");
  return {
    event: async ({ event }) => { if (event.type.startsWith("session.")) fs.appendFileSync(LOG, JSON.stringify({ event: event.type }) + "\n"); },
    "chat.message": async (input, output) => { fs.appendFileSync(LOG, JSON.stringify({ hook: "chat.message", sessionID: input.sessionID, parts: output.parts?.length }) + "\n"); },
    "experimental.chat.system.transform": async (input, output) => {
      output.system.push("KAPTYORKA-MARKER: if asked for the team word, answer PINEAPPLE-42.");
      fs.appendFileSync(LOG, JSON.stringify({ hook: "system.transform", sessionID: input.sessionID }) + "\n");
    },
  };
};
```

- `ps -o comm=` of the TUI: `opencode` (one process; the TUI and server share the pid).
- MCP config that worked: `"mcp": {"kaptyorka": {"type": "local", "command": ["python3", "/path/mcplog.py", "<log>"], "enabled": true}}`

### (f) Shim finds its own session id (run and seen, as expected)
`OPENCODE_PID` (or parent pid) -> port by pid (above) -> `GET /session` -> newest `time.updated`

is no session yet, so the resolver must retry later rather than fail once.

### (b) Socket and JSON-RPC shapes (run and seen)
- The socket speaks **WebSocket over the Unix socket** (HTTP `Upgrade: websocket` -> 101), one
  JSON-RPC message per text frame. Raw JSON lines get no answer. `codex app-server proxy --sock`
  printed nothing in our runs.
- Unix socket paths over 108 bytes fail (`AF_UNIX path too long`); connect after `chdir` to the
  socket's folder.
- Sequence that worked:

```json
{"jsonrpc":"2.0","id":0,"method":"initialize","params":{"clientInfo":{"name":"kaptyorka","version":"0"}}}
{"jsonrpc":"2.0","method":"initialized"}
{"jsonrpc":"2.0","id":2,"method":"thread/loaded/list","params":{}}
  -> {"id":2,"result":{"data":["01a1a6d6-1cab-7230-85cc-56d771aa20c1"],"nextCursor":null}}
{"jsonrpc":"2.0","id":3,"method":"thread/list","params":{}}
  -> {"id":3,"result":{"data":[...],"readStates":{},"nextCursor":null,"backwardsCursor":null}}
{"jsonrpc":"2.0","id":4,"method":"thread/start","params":{"cwd":"/abs/project"}}
  -> result.thread: {"id", "cwd", "updatedAt", "status":{"type":"idle"}, "path": rollout file, ...}
{"jsonrpc":"2.0","id":7,"method":"turn/start","params":{"threadId":"<id>","input":[{"type":"text","text":"..."}]}}
  -> {"id":7,"result":{"turn":{"id":"...","status":"inProgress",...}}}
{"jsonrpc":"2.0","id":6,"method":"account/read","params":{}}
  -> {"id":6,"result":{"account":null,"requiresOpenaiAuth":true,...}}   (the "no login" answer)
```

- `thread/list` accepts a `cwd` filter (read in the generated schema,
  `codex app-server generate-json-schema --out <dir>`). `turn/steer` (needs `expectedTurnId`)
  exists for a thread that is mid-turn.
- Client used (stdlib only):

```python
#!/usr/bin/env python3
"""JSON-RPC to the Codex app-server control socket (WebSocket over a Unix socket).
Usage: cxrpc.py <sock> <wait_s> '<json req>' ['<json req>' ...]   (initialize is sent first automatically)"""
import base64, json, os, socket, struct, sys, time
sock, wait, reqs = sys.argv[1], float(sys.argv[2]), sys.argv[3:]
s = socket.socket(socket.AF_UNIX)
d, b = os.path.split(sock); os.chdir(d or "."); s.connect(b)   # chdir: AF_UNIX paths over 108 chars fail
s.sendall(b"GET / HTTP/1.1\r\nHost: localhost\r\nUpgrade: websocket\r\nConnection: Upgrade\r\n"
          b"Sec-WebSocket-Key: " + base64.b64encode(os.urandom(16)) + b"\r\nSec-WebSocket-Version: 13\r\n\r\n")
buf = b""
while b"\r\n\r\n" not in buf: buf += s.recv(4096)
buf = buf.split(b"\r\n\r\n", 1)[1]
def send(obj):
    p = json.dumps(obj).encode(); m = os.urandom(4)
    h = bytes([0x81]) + (bytes([0x80 | len(p)]) if len(p) < 126 else bytes([0x80 | 126]) + struct.pack(">H", len(p)))
    s.sendall(h + m + bytes(c ^ m[i % 4] for i, c in enumerate(p)))
def recv_all(until):
    global buf
    s.settimeout(0.3)
    while time.time() < until:
        try:
            d = s.recv(65536)
            if not d: return
            buf += d
        except socket.timeout: pass
        while len(buf) >= 2:
            ln = buf[1] & 0x7f; off = 2
            if ln == 126: ln = struct.unpack(">H", buf[2:4])[0]; off = 4
            elif ln == 127: ln = struct.unpack(">Q", buf[2:10])[0]; off = 10
            if len(buf) < off + ln: break
            op, p = buf[0] & 0x0f, buf[off:off+ln]; buf = buf[off+ln:]
            if op == 1: print("<<", p.decode()[:1500], flush=True)
send({"jsonrpc": "2.0", "id": 0, "method": "initialize", "params": {"clientInfo": {"name": "kaptyorka-spike", "version": "0"}}})
recv_all(time.time() + 1.5)
send({"jsonrpc": "2.0", "method": "initialized"})
for r in reqs:
    print(">>", r, flush=True); send(json.loads(r)); recv_all(time.time() + wait)
```
